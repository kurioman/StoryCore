API REFERENCE
=============

All endpoints are under /api on http://127.0.0.1:<port>. JSON in, JSON out, unless noted.
Live interactive documentation with request/response schemas: http://127.0.0.1:8765/docs (Swagger) while the app runs.

Rules for clients:
  - Every POST / PUT / PATCH / DELETE needs the header  X-Story-Client: 1  (else 403).
  - Errors: {"detail": "<plain message>", "code": "<code>"} - codes: turn_error, not_found, invalid, no_model,
    cloud_consent_required (409), provider_error (502, with "error" details), internal (500).
  - Streams (text/event-stream): /api/generations/{mid}/stream (reply tokens), /api/ollama/pulls/{id}/stream.
  - Ids are UUID strings ({sid} story, {bid} branch, {mid} message, {wid} world, {pid} provider...).

The list below is generated from the routers (first line of each function's docstring, or its name).
To regenerate it after changes, see 09_HOW_TO.txt ("Regenerate the API list").
